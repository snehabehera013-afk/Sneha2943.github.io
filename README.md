# Sneha Behera — Portfolio Website

A clean, modern personal portfolio built with pure HTML, CSS, and JavaScript.
No frameworks, no build tools — just open `index.html` in any browser.

## Folder Structure

```
sneha-portfolio/
├── index.html          ← Main HTML (all sections)
├── css/
│   └── style.css       ← All styles, tokens, responsive
├── js/
│   └── main.js         ← Interactions, animations, form
└── README.md
```

## How to Run

Simply open `index.html` in your browser — no server needed.

```
# macOS
open index.html

# Windows
start index.html

# Or drag-and-drop the file onto any browser tab
```

## Sections

- **Hero** — Animated typing subtitle, key stats
- **About** — Background, research interests, quick-info card
- **Skills** — 8 categorised skill cards
- **Research** — 2 active research projects (live status badge)
- **Projects** — 3 featured projects with tech stack tags
- **Education** — Degree card with CGPA highlight
- **Contact** — Contact links + mailto-powered form

## Customisation

All design tokens (colors, fonts, spacing) live at the top of `css/style.css`
under `:root { ... }`. Change `--accent` to update the whole colour scheme.
